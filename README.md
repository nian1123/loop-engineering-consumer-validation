# Loop Engineering Consumer Validation

This is an independent, minimal Consumer Project used to validate the frozen `github-pr-review/v0.1.0` Candidate from `tutar/loop-engineering` against real GitHub pull requests and Check Runs.

It is evidence infrastructure, not a reusable library. Case records live in `validation/cases/` and must link to GitHub runs, pull requests, commits, and Checks. Static tests or Agent final text alone are not accepted as real compatibility evidence.
